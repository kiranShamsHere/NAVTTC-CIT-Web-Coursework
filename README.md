## 📄 About this repository

This repository is my daily practice log from the **Certification in IT (CIT) — Web Software & Mobile Web Development** course under the **National Vocational and Technical Training Commission (NAVTTC)**, completed February–March 2024.

It holds two kinds of work:
- **Daily class tasks** — what I built each day, in the order the course covered it.
- **Practice exercises** — smaller topic drills (CSS, JavaScript, jQuery, Bootstrap) done alongside the daily tasks to reinforce each concept.

🎓 **Course:** Certification in IT (CIT), Web Software & Mobile Web Development
🏛️ **Issuer:** National Vocational and Technical Training Commission (NAVTTC)
