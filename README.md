# Navttc2024

A structured archive of coursework from the CIT (Web Software and Mobile Web Development) certification under Pakistan's National Vocational and Technical Training Commission (NAVTTC), completed February to July 2024.

## What this is

Three parts, all from the same course.

`daily-tasks/` holds the day by day class assignments, in date order, from the start of the course.

`practice/` holds supplementary exercises grouped by topic (CSS, JavaScript, jQuery, Bootstrap), done alongside the daily coursework to reinforce specific concepts. These are not tied to a single date.

`syllabus-tasks/` holds the numbered tasks assigned directly from the course syllabus, split into two tracks by language: `web-fundamentals/` (HTML, CSS, JavaScript, jQuery, Bootstrap) and `php-basics/` (PHP). The PHP tasks need a PHP server to run and are not linked as live previews.

## Running locally

```bash
git clone https://github.com/kiranShamsHere/Navttc2024.git
cd Navttc2024
```

Open any task's `index.html` directly in a browser, or use the live preview links above. PHP tasks need a local PHP server, for example `php -S localhost:8000` run from inside the task folder.
